# pub_spushi_to_excel

Google スプレッドシートから、未エクスポート行だけを `.xlsx` で出力し、出力後にエクスポート列へ「済」を書き戻す Apps Script です。

## 使いどころ
- Googleフォーム等で集計されたスプレッドシートのデータを、未処理分だけ Excel（.xlsx）として出力したいとき
- 「スプシで集める → Excelで提出」が必要な業務（学校・団体・経理・名簿など）
- 出力済みを「済」で管理し、同じ行を二重処理したくないとき

## 最初にここだけ設定
テンプレートをコピーしたら、シート「設定」の値だけ変更すれば動きます。
- 対象シート名
- エクスポート列番号
- 出力ファイル名ベース
- 出力先フォルダID（空なら同じフォルダ、URL貼り付けでもOK）

## 使い方
1. テンプレート（閲覧専用）を開く  
   https://docs.google.com/spreadsheets/d/1dTPm5EB_o6ZUX1xqXoyTWjK3eFOwaKE2eCE2Ec0tMHc/edit?usp=sharing
2. 「ファイル → コピーを作成」で自分用に複製する  
3. シート「設定」を必要に応じて変更する  
4. メニュー「エクスポート → Excelに出力」をクリックする  

※ このテンプレートは直接編集せず、必ずコピーして使用してください。

## 動作仕様
- シート名・エクスポート列・出力名ベース・出力先フォルダは「設定」シートから読み込みます（初期値: `test`, `12`, `test`, 空）。
- エクスポート列が空欄の行だけを抽出します。
- エクスポート列を除外した Excel ファイルを生成します。
- Excel ファイルは、出力先フォルダIDがあればそのフォルダに、空なら元スプレッドシートと同じフォルダ（無ければマイドライブ直下）に作成されます。
- 正常終了後、対象行のエクスポート列に「済」を書き込みます。
- 破壊的操作（既存ファイル削除・上書き）は行いません。
